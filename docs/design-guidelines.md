# UI 设计规范 — 历史粘贴板

> 版本: v1.0 | 日期: 2026-07-02

---

## 设计原则

- **简洁**：去除一切非必要元素，让内容本身说话
- **直观**：用户不需学习，一看就懂怎么操作
- **原生感**：与 macOS 系统风格一致，像系统自带功能

---

## 布局规范

### 面板尺寸

| 属性 | 值 |
|------|----|
| 宽度 | 320pt |
| 最大高度 | 500pt |
| 最小高度 | 200pt |
| 圆角 | 12pt |

### 搜索栏

- 位于面板顶部，固定不随列表滚动
- 高度：36pt
- 占位文字："搜索历史..."
- 左侧放大镜图标（SF Symbol: `magnifyingglass`）

### 卡片

| 属性 | 值 |
|------|----|
| 内边距 | 水平 12pt，垂直 10pt |
| 卡片间距 | 6pt |
| 圆角 | 8pt |
| 背景色 | 浅色模式：灰色 0.05 透明度；深色模式：白色 0.08 透明度 |
| 悬停效果 | 背景加深 0.03 |

### 卡片内容布局

```
┌──────────────────────────────────────────────┐
│ 📝 文本内容预览（最多两行）...     ⏰ 时间   │
│                                         📌 ❌ │
└──────────────────────────────────────────────┘
```

- 文字预览：左对齐，最多 2 行，超出省略号
- 图片预览：缩略图 44×44pt，圆角 4pt，左对齐
- 时间标签：右上角，secondary 色
- 操作按钮：右下角，置顶 📌 + 删除 ❌，仅悬停时显示

### 空状态

- 居中显示 SF Symbol `clipboard`，尺寸 36pt
- 下方文字："暂无复制历史"
- 副文字："复制的文字和图片会自动出现在这里"
- 颜色：secondary 色

---

## 颜色方案

全部使用语义化颜色，自动适配深浅模式：

| 用途 | 颜色 |
|------|------|
| 面板背景 | `.windowBackgroundColor` |
| 卡片背景 | `.quaternarySystemFill` |
| 文字颜色 | `.labelColor` / `.secondaryLabelColor` |
| 强调色 | `.controlAccentColor` |
| 按钮色 | `.secondaryLabelColor`（悬停加深） |
| 分隔线 | `.separatorColor` |

不自定义任何固定颜色值，完全使用 AppKit 语义化颜色。

## 交互定义

| 操作 | 触发方式 | 反馈 |
|------|----------|------|
| 打开面板 | 点击菜单栏图标 | Popover 弹出，图标高亮 |
| 关闭面板 | 点击面板外任意处 或 再次点击图标 | Popover 收起 |
| 复制条目 | 点击卡片 | 内容写入剪贴板，面板收起 |
| 置顶/取消置顶 | 点击📌按钮 | 卡片立即移到顶部/恢复原位 |
| 删除 | 点击❌按钮 | 卡片移除，无需二次确认 |
| 搜索 | 输入文字 | 实时过滤，无结果时显示空状态 |
| 切换留存天数 | 点击分段选择器 | 即时生效，下次清理时按新规则 |

---

## 动画

- 面板弹出/收起：系统默认 NSPopover 动画
- 卡片出现：无动画
- 卡片移除：淡出 0.2s（`.easeOut`）
- 搜索过滤：无动画，即时显示结果
