# 产品需求文档 — 历史粘贴板

> 版本: v1.0 | 日期: 2026-07-02 | 状态: 开发中

---

## 产品概述

一款运行在 macOS 上的菜单栏历史粘贴板工具。自动记录文字和图片复制内容，以时间降序卡片展示，支持搜索、置顶、删除，可配置留存天数自动清理。

---

## 用户故事

- 作为 Mac 用户，我经常需要找回之前复制过的文字或图片，不想重复复制
- 我希望软件不打扰我，在后台安静运行，需要时能快速唤出
- 我希望能搜索历史记录，而不是在长列表中翻找
- 我希望能把重要的记录固定在顶部，方便查找
- 我希望数据只存本地，保护隐私

## 非功能需求

- **性能**：面板弹出延迟 < 200ms，列表滚动流畅
- **资源占用**：后台运行时内存占用 < 50MB
- **兼容性**：支持 macOS 14 Sonoma 及以上

---

## UI 形态确认

| 项 | 决定 |
|----|------|
| 软件形态 | 菜单栏小图标 → 弹出面板 |
| 点击行为 | 复制回剪贴板，手动 Cmd+V 粘贴 |
| 开发技术 | Swift 原生（SwiftUI + AppKit） |
| 数据存储 | 纯本地，无网络 |
