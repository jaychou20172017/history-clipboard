## 遇到的问题与解决

| 问题 | 解决 |
|------|------|
| 手动 pbxproj 不兼容 Xcode 26.6 | GUI 创建 + PBXFileSystemSynchronizedRootGroup |
| Color.quaternarySystemFill 不存在 | Color(nsColor:) 桥接 |
| @StateObject init 时机 | StateObject(wrappedValue:) 显式初始化 |
| App lifecycle 不触发 delegate | main.swift + NSApplicationDelegate 传统模式 |
| Timer 不触发 | RunLoop.main.add(.common) 替代 scheduledTimer |
| 沙盒拦截 debug 日志 | print() 输出 stdout |
